# TaskFlow — task tracker

Task tracker is a web-based productivity tool built with **React (Vite)** and **Spring Boot**,
designed to help people manage their assignments, deadlines and daily tasks. Its clean interface
and responsive design make it easy to stay organised.

**Full write-up, with architecture and code: [www.harishg.com/works/taskflow](https://www.harishg.com/works/taskflow)**

## Stack

- **Frontend** — React with Vite, TypeScript
- **Backend** — Spring Boot REST APIs with a DTO-based architecture
- **Database** — PostgreSQL
